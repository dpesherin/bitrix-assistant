# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).
Ведём с текущей версии.

## [0.3.2]

### Добавлено

- Обратная связь при загрузке на сервер: уведомление с прогрессом, зелёная галочка
  `$(check)` в статус-баре при успехе и красный крестик `$(error)` при ошибке.
  При автозагрузке по сохранению — только спиннер, без уведомлений.
- Колонка «Тип» в таблице параметров показывается всегда; тип берётся из сигнатуры,
  при её отсутствии — из `@param`.
- Подсветка сигнатуры в hover и карточке автодополнения: ключевые слова, классы,
  методы, переменные и значения теми же цветами, что и остальной hover.
- Горизонтальные разделители между блоками карточки; «Определение» — мелким
  приглушённым шрифтом внизу.
- Отступы внутри ячеек таблицы параметров и центрирование колонок «Тип»
  и «По умолчанию».
- Типы известных глобальных переменных: `$APPLICATION` → `CMain`, `$USER` → `CUser`,
  `$DB` → `CDatabase`, включая легаси-форму `$GLOBALS['APPLICATION']->`.
- Порядок членов класса в подсказках: свои → унаследованные → магические,
  внутри группы по алфавиту.
- Команда «Сравнить с сервером»: diff локального и серверного файла, при совпадении
  содержимого — статус вместо пустого diff.
- Команда «Терминал на сервере»: интерактивный shell по сохранённому SSH-профилю.

### Исправлено

- Автодополнение классов: `filterText` и диапазон замены согласованы с фильтрацией
  VS Code, поэтому `\CFile`, `\CCrmDeal` и подобные снова показываются.
- Подсказки для `\Bitrix\Main\…` больше не отсекаются фильтром глобальных классов.
- Имена трейтов, `extends` и `implements` резолвятся через `use`-импорты файла —
  методы трейтов видны в подсказках.
- Конфликт версий при загрузке решается по содержимому (размер + sha256): если файл
  на сервере новее, но содержимое совпадает, загрузка пропускается без вопроса.
- Самовосстановление индекса при `database disk image is malformed`; при атомарной
  перестройке не остаются `-wal`/`-shm` от прежней базы.
- SSH: при неудачной аутентификации пароль запрашивается один раз и сохраняется,
  поддержан `keyboard-interactive`; удалённый профиль не «воскресает» без пароля.
- Все команды, настройки и сообщения используют имя «Bitrix Assistant».

### Изменено

- Схема индекса 16 (требуется переиндексация при обновлении).
